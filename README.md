# SuperFood

Список покупок, рецепты с фото, меню на неделю и калории. Работает на iPhone (веб-приложение на экране «Домой»), Mac и Windows, синхронизация через Dropbox (тот же App key, что у Органайзера).

- **Покупки**: быстрый ввод строкой («молоко 2»), разбивка по отделам, свайп вправо — куплено, влево — удалить; список собирается из меню или рецепта.
- **Рецепты**: фото, ингредиенты вставляются текстом и разбираются сами, калории и БЖУ считаются по справочнику, метки «Пост», «Рыба», «Без изжоги» ставятся по продуктам, оценка полезности 1–10 с объяснением.
- **Меню**: подбор на неделю с ограничениями (нужно или исключить), завтрак/обед/ужин/перекус, гарниры и соусы к блюдам, граммы порций под цель по калориям, замена любого блюда, закрепление.
- Данные: только на устройствах и в вашем Dropbox; в репозитории код и общий справочник продуктов.
